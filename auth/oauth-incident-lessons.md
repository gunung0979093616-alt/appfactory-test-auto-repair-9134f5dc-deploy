# OAuth 成功與失敗經驗萃取

- OAuth resume loss after Google login breaks external connector authorization even when login itself succeeds.
- Missing credentials include on cross-origin login can prevent the backend session cookie from landing.
- Settings showing a connector is connected is not proof that the current chat loaded tools.
- Authorization approval should have a plain link-navigation route as the stable path for external clients.
- Unauthorized MCP or protected API probes should return an auth challenge, not data or a generic backend failure.
- Live proof must separate local plan, provider console setup, deployed callback, native ChatGPT or connector transcript, and review approval.
