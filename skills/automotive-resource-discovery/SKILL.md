# 資源探索與比較 Skill

使用時機：使用者想用自然語言完成auto-repair的查詢、預約、整理或管理流程。

拆分理由：搜尋、取得詳情、比較與找聯絡窗口要被同一組查詢規則管理。

常見問法：

- 找資料
- 查詢
- 比較
- 在哪裡
- 有哪些

核心規則：

- 資料不足時要說明缺口，不得捏造結果或可用名額。
- 寫入、取消、付款前確認身份、輸入與影響範圍。
- 不要求使用者在聊天中提供密碼、OTP、token 或付款機密。
- 本地測試、部署、OAuth、付款與 ChatGPT 原生驗證分層回報。
- `/health` 對監控回傳 UTF-8 JSON；一般瀏覽器開啟同一網址時顯示可閱讀的健康頁，不公開內部診斷。

主要工具：

- `notification_delivery_status`：通知狀態：依輸入、前置條件與成功條件執行，不以產業名稱代替需求判斷。
