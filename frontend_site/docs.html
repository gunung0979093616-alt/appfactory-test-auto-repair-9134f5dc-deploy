  • 幫我把服務項目寫得更像給客戶看的說明。
  • 幫我補一張適合這個產業的主視覺。
  • 幫我檢查手機版文字會不會太小或跑版。

使用者不用講工具名稱；系統會依需求判斷要調整文案、版面、圖片規格或使用說明。

測試時要看什麼

  1. 回答是否使用這個產業的正確詞彙。
  2. 是否有問到必要條件，而不是一次要求太多資料。
  3. 是否有提供來源、狀態、限制或確認提醒。
  4. 手機版是否能正常閱讀、點選與返回。

網站內容會依資料來源、服務狀態與使用者確認流程持續更新。
