第一階段交付後的使用說明

把你取得的外掛連到 ChatGPT，開始測試實際功能

這一頁教你在公開上架前使用與測試 汽車服務系統；正式公開上架後，請改用網站串接頁的品牌搜尋教學。

主要測試方式

在 ChatGPT 開發者階段新增自訂 MCP App

  1. 使用第一階段交付給你的 MCP 伺服器網址；網址通常以 /mcp 結尾。
  2. 在 ChatGPT 開發者階段新增自訂 MCP App，貼上你的 MCP 網址並連接。
  3. 用第一階段交付的正向、反向與模糊自然語言測試句驗證。
  4. 保留實際操作結果、對話紀錄或截圖，方便確認 ChatGPT 中的操作是否成功。

你的 MCP 網址：請使用第一階段交付的網址

第二種開發驗證

也可以在 Codex 直接連接自己的 MCP

到 Codex 設定 → 外掛程式 → 新增 MCP 伺服器 → 可串流 HTTP，填入名稱與你的 MCP 網址後儲存，再回到對話按「＋」選自己的外掛測試。

遇到問題怎麼辦

先確認網址、/health、/mcp 與部署版本屬於同一個專案。不要在聊天中提供密碼、驗證碼、Cookie、Token 或任何私密金鑰。
