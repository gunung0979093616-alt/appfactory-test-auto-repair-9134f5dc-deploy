網站圖片與素材

圖片要能上傳、能保存，也要知道什麼時候才算公開

圖片要能上傳、能保存，也要知道什麼時候才算公開。系統會先產生專屬背景範例圖、Logo 與主視覺位置；開發者也可以上傳商品圖、房源圖、菜單圖、案例圖或品牌素材。只有部署或授權儲存服務回傳 HTTPS 連結後，才標記為公開網址。

圖片網址怎麼成立

  1. 專案素材先放在可替換資料夾
  2. 帳號授權確認來源與使用範圍
  3. 上線驗證才可能得到 HTTPS URL
  4. 公開邊界未授權圖片不可公開

本機儲存

先放在專案內

網站用圖片、Logo、產業背景範例圖會先放在專案素材資料夾，並保留可替換位置。這些是本地檔案，不是公開網址。

公開網址

部署後才成立

網站部署、Cloudflare Images 或 Google Drive 分享連結，必須回傳可連線 HTTPS URL 並通過驗證，才能標示為公開素材。

素材上傳

要有來源與同意

餐飲、房地產、電商、美容、旅遊、課程等產業的圖片，都要記錄來源、用途、是否可公開、替換流程與錯誤回報。

上傳狀態

素材不是貼上就算完成，要有來源、用途、公開狀態與替換位置

第二階段會把 File Upload、3D Marquee、圖片濾鏡、素材牆與公開網址檢查串在一起：先收素材，再記錄授權，再進網站，最後用部署網址驗證。

產業背景圖

模板會先有看得出產業差異的背景，再讓開發者替換

目前已自動產生 industry-background.svg 並套用到每個頁面；背景圖只使用圖形與色彩，不嵌入文字，避免淡色殘影。這是免費本地範例圖，不會產生外部生圖成本；如果開發者要用ChatGPT 生圖、Canva、Figma 或自己的照片，系統會引導他完成帳號授權、上傳、替換並重新驗證。

自動產生的圖片規格

系統會先產生網站圖片規格與友善說明，再依規格建立這一頁。

  • 外掛 Logo / ChatGPT 上架圖示：256x256，PNG or SVG source + PNG export
  • 首頁主視覺：1600x900，WEBP or PNG
  • 社群分享圖：1200x630，PNG or WEBP
  • 功能卡片圖：800x600，WEBP or PNG

系統應自動建立的圖片規則

  • 如果專案需要圖片、Logo、作品集、設計預覽或影片縮圖，系統會自動建立上傳、儲存、授權與替換流程。
  • 每個產業網站至少要有 Logo、首頁主視覺、頁面背景圖與社群分享圖規格；背景圖不得所有產業共用同一張。
  • 如果使用 AI 生圖，成本與帳號授權由網站擁有者自己的帳號承擔；系統會協助記錄來源、放入網站並檢查顯示結果。
  • 沒有外部儲存授權時，先保留本地素材與可替換位置。
  • 需要公開網址時，引導使用者完成網站部署或自選儲存服務授權，不要求貼密碼、一次性驗證碼或金鑰。
  • 圖片連結確認可正常開啟前，不得在網站、交付說明或 ChatGPT 回答裡宣稱圖片已公開。

網站內容會依資料來源、服務狀態與使用者確認流程持續更新。
