Project-aware delivery

後台也要看得出整個專案階段

第一階段

外掛與 MCP 交付

需求、工具、Skill、Logo、專案 ZIP、MCP 與部署交接要能被第二階段讀取。

第二階段

網站前後端交付

首頁、方案、文件、後台、API 摘要、素材、Next.js/React/Tailwind 來源與網站 ZIP 要一起交付。

後續階段

登入、付款、送審、維運

未完成階段要標清楚下一步與本人授權邊界，不得假裝已完成。

污染守門

專案內容隔離

開發助手自建網站內容只能用於本體驗證；未來不同產業網站不得混入開發助手商業邏輯或其他客戶內容。

Verification layers

部署與驗證分層

  • 本地產出：確認檔案、頁面、測試與交付包存在。
  • 版本發布：確認正式版本與目前程式一致。
  • 服務連線：確認公開服務網址、健康狀態與工具連線可用。
  • 原生測試：確認在實際聊天介面可掃描、可呼叫、可完成正反向測試。
  • 送審狀態：確認隱私條款、客服入口、測試帳號、影片與審核資料齊全。
